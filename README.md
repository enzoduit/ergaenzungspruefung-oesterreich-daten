# Ergänzungsprüfungen Österreich: Datensatz (VWU Wien 2026/27)

Zitierbarer Datensatz zu den Ergänzungsprüfungen am Vorstudienlehrgang der Wiener Universitäten (VWU): alle Termine bis Juni 2027, Anmeldefristen, Gebühren (66 € / 46 €), das Format der schriftlichen EPD (180 Min., 75 Punkte, 45 zum Bestehen) und zentrale Regeln (max. 4 Wiederholungen, keine Anmeldung nach Fristende).

**Aktuelle Version & Seite:** https://vguh-vorbereitung.com/ergaenzungspruefung-oesterreich-daten/

## Dateien
- `data/ergaenzungspruefungen-vwu.json`: vollständiger Datensatz
- `data/termine-vwu.csv`: Termine und Fristen
- `data/gebuehren-vwu.csv`: Gebühren je Fach
